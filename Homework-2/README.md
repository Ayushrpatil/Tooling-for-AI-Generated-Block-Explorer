## 3. Bitcoin Core Deliverable on Windows

Your PDF uses macOS paths, but you are on Windows. The current official Bitcoin Core docs include a Windows/MSVC build path and a WSL path. On your machine, the most direct route is the Windows/MSVC build.

### Build Bitcoin Core

Open `Developer PowerShell for VS` and run:

```powershell
git clone https://github.com/bitcoin/bitcoin.git C:\src\bitcoin
cd C:\src\bitcoin
cmake -B build --preset vs2026-static
cmake --build build --config Release
ctest --test-dir build --build-config Release
cmake --install build --config Release --prefix C:\bitcoin-core-install
```

If the repo path has spaces or vcpkg complains about long paths, move the repo to a short path like `C:\src\bitcoin`.

### Generate RPC Auth

From the Bitcoin Core repo:

```powershell
python share\rpcauth\rpcauth.py student
```

That prints:

- an `rpcauth=...` line for `bitcoin.conf`
- the generated password you will use with `curl`

### Create `bitcoin.conf`

Create this file:

`%LOCALAPPDATA%\Bitcoin\bitcoin.conf`

Start from `bitcoin.conf.example` in this workspace and replace the placeholder `rpcauth` line with the one generated by `rpcauth.py`.

### Start the node

```powershell
C:\bitcoin-core-install\bin\bitcoind.exe -server
```

Leave it running. Sync takes a long time, but RPC will work before full sync completes.

### Prove `bitcoin-cli` works

In a second terminal:

```powershell
C:\bitcoin-core-install\bin\bitcoin-cli.exe getblockhash 0
```

Take your required screenshot of that terminal output.

### Prove raw RPC works with credentials

Replace `student` and the password with your generated values:

```powershell
curl.exe --user student:YOUR_GENERATED_PASSWORD --data-binary "{\"method\":\"getblockhash\",\"params\":[0],\"id\":1}" -H "content-type: text/plain;" http://127.0.0.1:8332
```

Expected result:

```json
{"result":"000000000019d6689c085ae165831e934ff763ae46a2a6c172b3f1b60a8ce26f","error":null,"id":1}
```
